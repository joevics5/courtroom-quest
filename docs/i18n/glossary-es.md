# Spanish (Latin America) courtroom glossary

Target: Latin American Spanish (es-419). Interface uses "tú"; speech inside the courtroom uses "usted".
This is a rewrite for how Spanish-speaking courts talk, not a word-for-word translation.
"Source" = where the term was seen in real court or law-school material. "Proposed" = standard usage, not verified yet.
